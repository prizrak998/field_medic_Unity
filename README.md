# field_medic_Unity
Прототип игры на Unity про полевого медика
# Как играть:
Появляется раненый с описанием ранений, вы выбираете медикамент которым нужно лечить, и нажимаете на поврежденную часть тела, выполняя мини-игру<br/>
***Мини игры:***<br/>
1. Жгут: крутить колесом мыши(главное не перетянуть)<br/>
2. Бинт: Водить мышкой по кругу<br/>

*чтобы играть, надо скачать всё и запустить .exe файл*
